Key Points

• WebMCP makes a website agent-readable and agent-actionable through a short, clear list of tools.
• The browser session carries the login, so tools stay conditional and the setup stays simple.
• The live store demo compares machines, matches accessories, adds to the cart, and applies a coupon.
• WebMCP sits between headless APIs and in-app agents, and it keeps the visual UI that most people prefer.

Numbered Section Summaries

1. What WebMCP Is Vince describes WebMCP as MCP in the UI, in the browser. It is an experimental feature from Google and Microsoft, so early builders get a first mover advantage. I put it in one line: websites with agent buttons.

2. The Espresso Store Demo Vince starts from his own problem. He wants to upgrade from a Mara X machine, and he needs one that makes two flat whites a day and fits a 32 cm counter. His agent talks to the store, puts two machines side by side, and highlights the specs that match the request.

3. From SEO To AEO To Agent Execution I frame the shift in three steps. SEO asks if Google understands the page. AEO asks if AI cites the answer. WebMCP asks if the agent finishes the job, and that is where billions of dollars will change hands.

4. Login State As The Auth Layer Tools stay conditional on the browser session. Vince logs in and the full tool list appears, and he logs out and three tools remain. The agent shares the session, so the login covers the access, and API keys and tokens stay out of the flow.

5. The Agent-Native Map Vince walks through his diagram: raw APIs and classic MCP servers stay headless, computer use and browser MCP read screenshots and the whole DOM, and in-app agents keep the user inside your product. WebMCP lands in the middle. It gives the app agent capabilities while the user brings the agent that already holds their context and memory.

6. Where WebMCP Fits First Vince names compatibility-driven commerce as the top use case, plus complex stores like camera systems. SaaS admin, analytics, and marketing consoles follow. Regulated sectors such as insurance and banking self-service can ship read-only tools that guide the user, and internal tools give founders a safe place to start.

7. Startup Idea 1: WebMCP Conversion Agency I pitch an agency that makes boring business websites agent ready: law firms, HVAC and home services, med spas, and dentists. You ship V1 tools such as request a quote and book a consult, charge $2,000 to $10,000 for setup, and keep a few hundred to $700 per month for monitoring and evals. Vince suggests you sell it as a package across MCP, WebMCP, and internal tools, so you own the expert seat while the standard matures.

8. Startup Idea 2: The Agent Mystery Shopper The second idea tests whether agents complete the journeys that matter: buy the hoodie, book the consult, file the claim, reorder the item. The customer gets a recurring report on where the agent stalls, which descriptions read poorly, which tools are absent, and where conversion risk sits. Price it near $100 to a few hundred per month, turn the repeat fixes into software, and pair it with the conversion agency as a lead source.
