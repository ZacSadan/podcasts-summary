[SHOW NOTES]
I vibe coded a full game sequel using Claude Code and Codex, and it proved something important about AI and game development.

A year ago I built The Librarian, a playable vibe coded game you can still find on GitHub. This time I wanted to see how far AI coding tools have come, and whether one person could build something that actually feels like a real game.

I used Claude Code with Opus 5 for the initial build, then switched to Codex and GPT-5.6 Sol for all the fine-tuning. The result is The Librarian 2, a 3D procedurally generated roguelite with boss enemies, natural disasters, meta progression, and a chaos system. 10,400 lines of code across 33 modules. Zero asset files.

The verdict: game development is far from cooked. But it's also a lot harder than the one-level demos on X make it look.
