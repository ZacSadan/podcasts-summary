What happens when a packet takes an unexpected turn? Can Check Point Maestro keep a connection on track even when NAT sends the reply to a different Security Group Member?

In the final episode of the Maestro Packet Journey series, The Check Point’s Technical Marketing Engineering team explores the Correction Layer - the mechanism that handles asymmetric connections in a multi-SGM environment.

Follow a real packet-flow scenario to see how NAT changes an address, how the return traffic reaches a different Security Group Member (SGM), and how Maestro redirects the packet to the original connection owner. Discover how connection synchronization enables a single SGM to handle the entire flow, preserving stateful inspection and security protections even when traffic takes an unexpected path.

Then, explore the Maestro Insights dashboard to see how you can monitor corrections, investigate traffic, and troubleshoot connections across Security Group Members.

Finally, bring the entire journey together—from the Orchestrator’s traffic distribution, through SGM connection ownership and inspection, to the Correction Layer that keeps asymmetric traffic on track.

One packet. One journey. One Maestro.
