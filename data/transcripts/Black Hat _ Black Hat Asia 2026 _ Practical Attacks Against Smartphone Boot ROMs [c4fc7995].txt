[SHOW NOTES]
Boot ROMs are an immutable component of any hardware platform, and vulnerabilities in them can compromise the entire boot chain. This talk aims to outline the impact of vulnerabilities in the USB interface of smartphone Boot ROMs at a low level, demonstrating how a smartphone's entire ecosystem can be manipulated from a single vulnerability.

Using example targets from two different manufacturers, this talk aims to outline the impact of code execution vulnerabilities in multiple boot stages of a smartphone, providing practical demonstrations of secure boot bypass on mobile devices, on-device fuzzing, and decryption of protected firmware images.
