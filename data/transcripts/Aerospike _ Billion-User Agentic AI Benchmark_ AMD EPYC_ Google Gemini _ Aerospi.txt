Aerospike, AMD, and Google Cloud have jointly developed a billion-user agentic AI benchmark that stress-tests real-time AI workloads at a scale most databases cannot handle. This benchmark runs 1 billion simulated users, 3 billion-plus payments, and 100,000 concurrent AI agents on 5th Gen AMD EPYC processors, Google Cloud C4D machines, and the Aerospike real-time database to prove that production-grade agentic AI is achievable today.

What this benchmark covers and why it matters:

• Agentic AI fan-out query architecture: A single agentic workflow triggers multiple sequential steps, and each step fans out into multiple simultaneous database queries, placing extreme read and write pressure on any data layer not built for this pattern.
• Why AI is making every application look like fraud detection: Higher data volume per interaction drives higher fan-out, greater sensitivity requirements, and non-steady-state traffic patterns that mirror the most demanding fraud detection systems in production today.
• The full fraud investigation workflow demonstrated end to end: From a fraud analyst opening a flagged account case, through automated specialist agent analysis, to a final actionable case report and real-time transaction enforcement.
• Case Prep Agent: Gathers the alert, relevant account data, and prior case history before any analysis begins, ensuring every downstream agent has full context.
• Network Analyst Agent: Maps account rings, money mules, and suspicious fund flows across connected entities.
• Device Analyst Agent: Identifies shared, cloned, or spoofed devices linked to known fraud patterns.
• Velocity Analyst Agent: Detects unusual transaction bursts, abnormal amounts, and behavioral anomalies signaling suspicious activity.
• Lead Investigator Agent: Synthesizes all specialist findings into a single consolidated assessment ready for action.
• Scribe Agent: Converts the consolidated assessment into a complete, audit-ready case report.
• Enforcer Agent: Uses the finalized report to propose the next business action, whether that is blocking, flagging, or escalating.
• Human-in-the-loop design: The human analyst retains the ability to approve, override, or escalate any proposed action before it is enforced.
• Real-time enforcement: When fraud is confirmed, the system flags the account and associated devices immediately to intercept the next transaction before it clears.
• Aerospike as the real-time data backbone: Agent memory, short-term case context, long-term historical investigation knowledge, graph relationship analysis, and the online feature store all operate within the Aerospike cluster, delivering the sub-millisecond latency that agentic workflows demand.
• Short-term memory layer: Keeps active case context live across every agent step so the workflow builds coherently without re-fetching state.
• Long-term memory layer: Preserves historical investigation outcomes so the system continuously learns from prior fraud cases and improves decisioning over time.
• Graph relationship analysis: Surfaces hidden connections between accounts, devices, and transactions that individual record lookups would miss entirely.
• Online feature store: Provides live signals and precomputed features to every agent so decisions are made on the most current data available.
• Google Gemini reasoning layer: Orchestrates agent coordination and interprets complex multi-signal findings across the investigation pipeline.
• 5th Gen AMD EPYC on Google Cloud C4D: Delivers the raw compute throughput required to sustain 100,000 concurrent agents without performance degradation.
• Benchmark result: 90 percent reduction in fraud investigation time. At billion-user scale, every second of investigation delay is a direct financial and reputational cost.

This benchmark is built for engineering and architecture teams evaluating real-time databases for agentic AI, fraud detection, financial services, and high-throughput decisioning platforms. It demonstrates concretely how Aerospike, AMD EPYC, and Google Cloud Gemini combine to support the most demanding AI workloads in production, from fintech and payments to any application where AI agents must read, reason, and act on live data at scale. Whether you are designing a new agentic system or modernizing an existing fraud platform, this reference architecture provides a validated, production-proven foundation.
