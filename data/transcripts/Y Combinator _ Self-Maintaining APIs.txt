[SHOW NOTES]
APIs change constantly, but the way providers communicate those changes is still broken. Breaking updates go unnoticed, new features get buried in changelogs, and customers often find out only after something stops working.

Coding agents make a better model possible. Instead of announcing a change, an API provider could find every affected use in a customer’s codebase and open the pull request itself.
