[SHOW NOTES]
This project is an IoT-based Smart Washroom Monitoring System that enhances hygiene, occupancy monitoring, and maintenance efficiency in public washrooms. The system is built around the Seeed Studio XIAO ESP32S3, which interfaces with multiple sensors and display modules to provide real-time monitoring.

A VL53L0X Time-of-Flight (ToF) distance sensor is used to detect toilet occupancy by measuring the distance between the sensor and the user. Based on the measured distance, the system determines whether the washroom is occupied or vacant. A 0.96-inch SSD1306 OLED display shows real-time information such as occupancy status, measured distance, total washroom usage count, and soap usage count, making the system easy to monitor locally. https://www.hackster.io/nova/smart-restroom-occupancy-monitor-ffd8c1
