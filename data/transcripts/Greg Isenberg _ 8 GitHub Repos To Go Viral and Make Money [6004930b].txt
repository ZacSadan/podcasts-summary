Numbered Section Summaries

1. Brag

I start with Brag, a skill that turns your project or a website link into a short launch video with music, motion, and post copy. I use Brag Slim, which is designed for Opus 5.5. You pick vertical, square, or landscape and redo any scene that feels off.

2. Agent Reach

Agent Reach sets up the tools your agent needs to research a topic across YouTube, Reddit, and X. I use it for customer research. I search phrases like "I export it," "I copy this into," and "does anyone know a workaround," then talk to the people behind the posts.

3. Voice Studio
Voice Studio is a desktop app for AI voice work, similar to 11 Labs. It runs local models on your own hardware, so a faster computer helps. It generates speech, works from a recording of your own voice, and dubs video into other languages. I'd start with a short recording of myself, then translate the tutorials behind the three most common support questions, with a fluent speaker checking the result.

4. PPT Master

PPT Master turns documents or notes into an editable presentation, and it accepts your own company template. I'd test it first on a proposal I already wrote, with the private information removed, so I know what a good result looks like.

5. OpenRig

OpenRig organizes coding agents into a team, so one agent builds a change, another checks it, and the work passes between them. It works with Codex and Claude Code, runs on Mac or Linux with Node and Tmux, and changes some agent settings, so read those before you run it.

6. Free Tools 

Free Tools is a skill from Corey Haynes's marketing collection. It helps you work out what to build and give away to attract the right customers. A skill is a reusable set of instructions for your agent, sometimes with scripts and examples, so you stop rewriting giant prompts every time.

7. Grill Me

Grill Me, a skill by Matt Pocock, interviews you about an idea or decision in rounds and follows up on your answers. I'd use it before I build something I'm excited about, because that's when I skip the awkward questions.

8. Impeccable

Impeccable, built by Paul Bakaus, gives coding agents specific design guidance once you tell it who the product is for. It has commands like critique, polish, bolder, and quieter. I'd run critique on a page
